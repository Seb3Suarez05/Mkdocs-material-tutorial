### FNG Onboarding Guide 

This guide is designed to help you get started with the tools you'll be using as an intern. Don’t worry if you’ve never used the terminal or Git before—everything here is broken down to make the learning process smoother.


### The thing you need to learn

=== "1. Prerequisites"

    <a href="https://www.warp.dev" target="_blank">Warp Terminal</a>

     Warp is a beginner-friendly terminal for Mac. It offers helpful features like color coding, suggestions, and built-in AI assistance for troubleshooting. While you can use the default Mac terminal, Warp is highly recommended.

    <a href="https://code.visualstudio.com" target="_blank">Visual Studio Code</a>
 
     You won’t need this right away when learning Bash, but once you begin working with Git, GitHub, and MkDocs, VS Code will be essential. It integrates with Warp, and you can easily open your folders by dragging and dropping them into the editor.


=== "2. Homebrew and Bash"

    <a href="https://brew.sh" target="_blank">Homebrew</a>

    Open your terminal, type bash, and paste the installation command from the Homebrew site. This tool lets you install other important software easily.
    
    ### Video Guide
    <a href="https://youtube.com/playlist?list=PLT98CRl2KxKGj-VKtApD8-zCqSaN2mD4w&feature=shared" target="_blank">Learn Bash</a>
    
    This video playlist walks you through Bash basics in a practical way. Highly recommended if you prefer learning through videos.

    ### Written Guides
    <a href="https://guide.bash.academy" target="_blank">Bash</a>

     A more advanced written guide. You can refer to this if you get stuck or want extra practice.


=== "3. Git and Git  Submodules"
    ### Git Video Guide

    <a href="https://youtu.be/zTjRZNkhiEU" target="_blank">Git Video Introduction</a>

     Git is a tool that helps you track changes in your code over time. Think of it like a timeline of all the work you've done—it lets you go back to older versions, experiment without breaking things, and work on the same project with others without confusion.

    ### Git Written Guides

     <a href="https://www.w3schools.com/git/default.asp" target="_blank">W3Schools Git Guide</a>
     
     <a href="https://www.freecodecamp.org/news/guide-to-git-github-for-beginners-and-experienced-devs/" target="_blank">FreeCodeCamp Git & GitHub Guide</a>

     You’ll use Git in your terminal (ideally Warp) and once you get used to the basic commands like git add, git commit, and git push, it becomes second nature. Take your time learning it, Git is one of the most important tools in a developer’s toolkit.

    ### Git Submodules Video Guide
     <a href="https://youtu.be/gSlXo2iLBro" target="_blank">Git Submodules</a>
    
    Submodules are like putting one Git project inside another. You won’t use this right away, but it’s helpful to understand later on when you’re dealing with bigger projects that rely on smaller parts. This video is a great resource once you're comfortable with Git and want to learn more.


=== "4. GitHub"
    ### GitHub Video Guide

    <a href="https://youtu.be/iv8rSLsi1xo" target="_blank">GitHub Setup Video</a>

    GitHub is the website where all your code and Git work gets uploaded, shared, and managed. Think of it like Google Drive for code—but with extra features for teamwork and tracking changes.
    You’ll need a GitHub account and the GitHub Desktop app to get started. Most of the time, you’ll be pushing code from your computer to GitHub so others (or future-you) can access and collaborate on it.
    


=== "5. Git + GitHub Combined/ optional but recomended"
    ### GitHub Video Guide

    <a href="https://youtu.be/l2yrJtwoC_E" target="_blank">Git + GitHub Combined Tutorial</a>

    This is the video I recommend watching after you understand Git and GitHub separately. It puts everything together—how to use Git commands and push that work to GitHub. It covers key ideas like:
    
    git push: Sending your work online

    git pull: Getting the latest updates

    git fetch: Checking for changes without merging

    Seeing both tools in action together will make a lot of things click, especially once you start working with others or across multiple devices.

=== "6. MkDocs"
    ### MKdocs Video Guide

    <a href="https://www.youtube.com/watch?v=xlABhbnNrfI" target="_blank">MkDocs Video Tutorial</a>

    MkDocs is a tool that helps you build clean, professional websites to show off your project documentation. It uses Markdown (a simple way to format text) and turns it into a full website—no web design skills needed.
    This is especially helpful for explaining your projects, writing up how things work, or building personal websites or technical portfolios. You’ll use VS Code to write the Markdown, and Warp to run the MkDocs commands.
